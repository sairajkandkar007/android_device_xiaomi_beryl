# OrangeFox Recovery device tree — Xiaomi POCO M7 Pro 5G (beryl)

- Codename: beryl
- Platform: MediaTek MT6855
- Android base: Android 16
- Recovery: vendor_boot v4 recovery ramdisk
- Storage: A/B, Virtual A/B, dynamic partitions

The device-specific values were derived from stock beryl images and cross-checked
against the public TWRP-generated beryl device tree.

vendor_boot recovery is an experimental OrangeFox configuration. Do not flash an
untested image.
